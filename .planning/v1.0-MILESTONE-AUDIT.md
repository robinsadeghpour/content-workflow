## Critical Integration Bug

**Status string mismatch between Phase 3 and Phase 4**

| File | Writes/Reads | Value |
|------|-------------|-------|
| `scripts/apply-critic.js` | WRITES to DB | `critic_approved` (underscore) |
| `scripts/approve-draft.js` | READS from DB | `critic-approved` (hyphen) |

**Impact:** The entire publishing pipeline is dead. After the critic agent approves a draft, Robin runs `/approve` and sees "No drafts pending approval." Nothing can be published to any platform.

**Fix:** Standardize on one separator in both files. Also update `VALID_TRANSITIONS` starting state from `'draft'` to `'generated'`.

**Affected requirements:** PUBL-01, PUBL-02, PUBL-03, PUBL-04 (directly), PUBL-05, ANLY-01–03 (downstream — no posts = no analytics)
