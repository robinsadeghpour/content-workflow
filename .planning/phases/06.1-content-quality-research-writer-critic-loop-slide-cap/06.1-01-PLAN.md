2. Creates `data/research/` if missing.
3. Target output: `data/research/${IDEA_ID}.md`. If the file already exists, echo the path and exit 0 (cache hit — D-08 reusability). Support `FORCE_RESEARCH=1` env var to bypass cache.
4. Runs the NotebookLM pipeline using ONLY `-n $NOTEBOOK_ID` (never `notebooklm use`):
   - `notebooklm create "Research: $IDEA_TITLE" --json | jq -r .id` → NOTEBOOK_ID
   - If NOTEBOOK_ID is empty or "null", set `RESEARCH_THIN=true` and skip to write step
   - If `TRANSCRIPT_FILE` is non-empty and exists: `notebooklm source add "$TRANSCRIPT_FILE" -n "$NOTEBOOK_ID" --json` (fail-open with `|| true`)
   - If `IDEA_URL` is non-empty: `notebooklm source add "$IDEA_URL" -n "$NOTEBOOK_ID" --json` (fail-open)
   - `notebooklm source add-research "$IDEA_TITLE last 30 days" --mode fast -n "$NOTEBOOK_ID" --import-all` (fail-open)
   - `notebooklm source wait -n "$NOTEBOOK_ID" --timeout 180` — on non-zero exit set `RESEARCH_THIN=true`
   - `ANSWER=$(notebooklm ask "Produce a 300-500 word research brief with: (1) 3-5 bullet key facts, (2) 3-5 quotes or stats with attribution, (3) source list with URLs and dates, (4) 2-4 content angle suggestions (contrarian, data-driven, story-driven). Bias toward info from the last 30 days. If you don't have enough information, say so explicitly." -n "$NOTEBOOK_ID" --json 2>/dev/null | jq -r .answer)`
   - Heuristic thin detection: if `ANSWER` is empty OR `${#ANSWER} -lt 200` OR `ANSWER` matches `-qi "don't have enough"` → set `RESEARCH_THIN=true` and replace ANSWER with `"(Research returned insufficient info. Writer should lean on idea.title / idea.summary / idea.transcript.)"`
5. Writes the brief file via heredoc (NOT echo) with YAML frontmatter (idea_id, researched_at ISO8601 UTC, research_thin boolean, notebooklm_notebook_id) followed by `# Research Brief: $IDEA_TITLE` heading and the ANSWER body.
6. Prints the brief path to stdout (last line) so the orchestrator can capture it: `echo "$BRIEF_PATH"`.
7. Always exits 0 — research-thin is NOT a hard failure (D-05). Only exit non-zero on catastrophic scripting errors (missing args).

Use `set -uo pipefail` at the top (NOT `set -e` — we want fail-open on notebooklm calls). Add a shebang `#!/usr/bin/env bash`.

Copy the full tested shape from 06.1-RESEARCH.md Example 1 (lines 619-663) as the starting point and extend it with the transcript-file handling + cache-hit short-circuit.
