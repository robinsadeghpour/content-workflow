### WR-02: NotebookLM heredoc vulnerable to early termination

**Files modified:** `scripts/research/run-notebooklm.sh`
**Commit:** `a3820b9`
**Applied fix:** Replaced the `cat > "$BRIEF_PATH" <<EOF ... EOF` block with a brace-grouped pair of `printf` calls. First `printf` emits the YAML frontmatter and markdown heading using `%s` substitution; second `printf '%s\n' "$ANSWER"` pipes the answer body. This eliminates the heredoc delimiter-collision risk entirely (a lone `EOF` line in the model output can no longer terminate the write). As a side benefit, the notebook id now defaults to `none` via `${NOTEBOOK_ID:-none}` so the frontmatter field is never emitted empty. Verified with `bash -n` syntax check.
