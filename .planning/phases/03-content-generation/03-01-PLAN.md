**Script 1 -- scripts/generate-tiktok-slides.js:**
Fork Larry's `add-text-overlay.js` with these modifications per D-04 and D-05:

CLI interface:
```
node generate-tiktok-slides.js --photos <photos.json> --texts <texts.json> --output <dir>
```
- `--photos`: JSON array of absolute photo file paths (one per slide)
- `--texts`: JSON array of text strings (one per slide, same length as photos)
- `--output`: directory to write final PNGs

Key changes from Larry's original:
1. **Remove hardcoded 6-slide check** (line 44 of original: `texts.length !== 6`). Replace with:
   ```javascript
   if (texts.length < 2 || texts.length > 12) {
     console.error('Slide count must be 2-12, got ' + texts.length);
     process.exit(1);
   }
   if (texts.length !== photos.length) {
     console.error('texts and photos arrays must be same length');
     process.exit(1);
   }
   ```

2. **Accept photos array argument** instead of scanning directory for `slide{N}_raw.png`. Each photo path comes from the JSON array (sourced from catalog.json by the orchestrator).

3. **Keep all text rendering logic identical** to Larry's proven pattern:
   - `fontSize = Math.round(img.width * 0.065)` (6.5% of width)
   - `outlineWidth = Math.round(fontSize * 0.15)` (15% outline)
   - `maxWidth = img.width * 0.75` (75% text width)
   - `lineHeight = fontSize * 1.25` (125% line height)
   - Safe zones: top 10% (`img.height * 0.10`), bottom 20% (`img.height * 0.80`)
   - White fill `#FFFFFF` + black outline `#000000`
   - Bold Arial font
   - Center-aligned text at ~30% from top

4. **Keep the wrapText function** exactly as Larry's (strips emoji via `[\u{1F300}-\u{1FAFF}\u{2600}-\u{27BF}]` regex, supports `\n` manual breaks, auto-wraps remaining).

5. **Output naming**: `slide-01.png`, `slide-02.png`, etc. in the `--output` directory. Use zero-padded numbers.

6. **Create output directory** if it doesn't exist (`fs.mkdirSync(outputDir, { recursive: true })`).

7. **Exit with JSON summary** to stdout: `{"slides": N, "output_dir": "...", "files": ["slide-01.png", ...]}`.

**Script 2 -- scripts/generate-ai-slides.js:**
AI image generation fallback per D-01 (Nano Banana / Gemini, NOT OpenAI gpt-image-1.5).

CLI interface:
```
node generate-ai-slides.js --prompts <prompts.json> --output <dir>
```
- `--prompts`: JSON array of image generation prompts (one per slide)
- `--output`: directory to write generated PNGs

Implementation:
1. Load `GEMINI_API_KEY` from `.env` via `require('dotenv').config()`.
2. For each prompt in the array, call Gemini API directly (not via Python -- keep it pure Node.js for consistency with the pipeline):
   ```javascript
   const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-image:generateContent?key=${process.env.GEMINI_API_KEY}`;
   const payload = {
     contents: [{ parts: [{ text: prompt }] }],
     generationConfig: { responseModalities: ["IMAGE", "TEXT"] }
   };
   ```
3. Use native `fetch` (Node 20+). Parse response, extract base64 image data from `response.candidates[0].content.parts` (find the part with `inlineData`).
4. Write each image as `slide-01.png`, `slide-02.png` etc. to output dir.
5. Use `p-limit` (v4, CJS) with concurrency 3 to avoid rate limiting:
   ```javascript
   const _pLimit = require('p-limit');
   const limit = (_pLimit.default || _pLimit)(3);
   ```
6. If `GEMINI_API_KEY` is not set, exit with error code 1 and message: `"GEMINI_API_KEY not set in .env -- cannot generate AI slides"`.
7. Exit with JSON summary: `{"slides": N, "output_dir": "...", "files": ["slide-01.png", ...]}`.

Both scripts use `'use strict'` and CommonJS (`require`).
