Create `scripts/generate-linkedin-content.js` — a CommonJS Node.js script.

**CLI interface:**
```
node generate-linkedin-content.js --idea-json <idea.json> --format <carousel|text|infographic|personal> --output <dir>
```
- `--idea-json`: path to a JSON file with idea data: `{ id, title, summary, transcript, source_url, source_type, content_angle_suggestion }`
- `--format`: one of `carousel`, `text`, `infographic`, `personal`. If omitted, auto-suggest using heuristics (see below).
- `--output`: directory for output files

**Format auto-suggestion (D-06):**
When `--format` is not provided, determine format from the idea JSON:
```javascript
function suggestFormat(idea) {
  const title = (idea.title || '').toLowerCase();
  const angle = (idea.content_angle_suggestion || '').toLowerCase();
  
  if (angle.includes('tutorial') || /\b(how to|guide|step|tutorial|tips)\b/.test(title)) return 'carousel';
  if (angle.includes('hot take') || /\b(wrong|actually|unpopular|controversial|opinion)\b/.test(title)) return 'text';
  if (angle.includes('news') && /\d/.test(idea.summary || '')) return 'infographic';
  if (idea.source_type === 'founder_note' || angle.includes('story')) return 'personal';
  return 'text'; // safest fallback
}
```

**Format: carousel (LINK-01, D-07):**

2. Generate slide content structure as JSON: `{ slides: [{ title, body, slide_number }] }`. The number of slides depends on the content — typically 5-10 for tutorials.
3. Write a temporary HTML file at `<output>/linkedin-carousel.html` that injects the slide content into the template structure. Each slide is a `<div class="slide">` element.

5. The screenshot script outputs slide PNGs + `linkedin-carousel.pdf`.
6. Output JSON result: `{ "format": "carousel", "post_text": "...", "html_path": "...", "pdf_path": "...", "slide_count": N }`.

**Format: text (LINK-02):**
1. Generate a LinkedIn post text from the idea summary/transcript.
2. Structure: hook line (first sentence, attention-grabbing), body paragraphs, call-to-action.
3. No visual pipeline needed.
4. Output JSON: `{ "format": "text", "post_text": "..." }`.

**Format: infographic (LINK-03, D-08):**
1. Extract key data points/insights from the idea summary and transcript.
2. Compose a Gemini image prompt for a portrait infographic (1080x1350): include data points, brand colors (from slide-template.html CSS vars), clean modern design instruction.
3. Call Gemini API (same pattern as generate-ai-slides.js):
   ```javascript
   const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-image:generateContent?key=${process.env.GEMINI_API_KEY}`;
   ```
4. Save the generated image as `<output>/infographic.png`.
5. Generate accompanying post text.
6. Output JSON: `{ "format": "infographic", "post_text": "...", "image_path": "...", "data_points": [...] }`.

**Format: personal (LINK-04):**
1. Take the idea summary as rough notes.
2. Generate a polished personal LinkedIn post — first-person voice, reflective tone, storytelling structure.
3. No visual pipeline by default. Include `"image_optional": true` in output so the orchestrator can decide.
4. Output JSON: `{ "format": "personal", "post_text": "...", "image_optional": true }`.

**All formats:**

- Print the JSON to stdout.
- Load `.env` via `require('dotenv').config()` at the top.
- Use `'use strict'` and CommonJS.
- The script generates RAW content structure only — voice application (humanizer pass) is handled by the orchestrator in Plan 03.

**IMPORTANT:** The script generates content text directly using string templates and heuristics. It does NOT call the Claude API itself — that responsibility belongs to the orchestrator (Plan 03) which calls `@anthropic-ai/sdk` for actual content generation with voice profiles. This script structures the pipeline routing, file I/O, and format-specific processing (HTML assembly, Playwright invocation, Gemini calls for infographics).

Content text generation approach:
- For `carousel`: The script receives pre-generated slide texts from the orchestrator via `--slide-texts <texts.json>` (optional arg). If provided, it assembles them into HTML. If not provided, it outputs a skeleton that the orchestrator fills.
- For `text` and `personal`: The script receives the draft post text via `--post-text <text_file>` (optional arg). If provided, it writes the output JSON. If not, outputs skeleton.
- For `infographic`: Handles the Gemini API call directly (image generation is not a Claude task) and receives accompanying text via `--post-text`.

This separation keeps Claude API calls centralized in the orchestrator while format-specific I/O (HTML assembly, screenshot, image generation) lives in this script.
