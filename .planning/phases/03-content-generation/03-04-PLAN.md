Create `scripts/apply-critic.js` — the critic agent. CommonJS, `'use strict'`.

**CLI interface:**
```
node apply-critic.js --idea <idea_id>
```
Processes ALL drafts for the given idea_id that have `status = 'generated'`.

**Dependencies:**
```javascript
'use strict';
require('dotenv').config();
const Anthropic = require('@anthropic-ai/sdk');
const Database = require('better-sqlite3');
const fs = require('fs');
const path = require('path');
```

**Core logic:**

1. Load all drafts for the idea_id with `status = 'generated'`:
   ```javascript
   const db = new Database(path.join(__dirname, '..', 'data', 'content.db'));
   const drafts = db.prepare('SELECT * FROM drafts WHERE idea_id = ? AND status = ?').all(ideaId, 'generated');
   const idea = db.prepare('SELECT * FROM ideas WHERE id = ?').get(ideaId);
   ```

2. Load voice profiles:
   ```javascript
   const voiceCasual = fs.readFileSync(path.join(__dirname, '..', '.claude/skills/writing/data/voice-casual.xml'), 'utf-8');
   const voiceLinkedin = fs.readFileSync(path.join(__dirname, '..', '.claude/skills/writing/data/voice-linkedin.xml'), 'utf-8');
   ```

3. For each draft, run the critic as a SEPARATE Claude API call (D-12 — fresh context, no generation history):
   ```javascript
   const anthropic = new Anthropic();
   const MAX_ATTEMPTS = 3;
   
   for (const draft of drafts) {
     const content = JSON.parse(draft.content);
     const voiceProfile = draft.platform === 'linkedin' ? voiceLinkedin : voiceCasual;
     const isSlideContent = ['tiktok_en', 'tiktok_de', 'instagram'].includes(draft.platform) || content.type === 'linkedin_carousel';
     
     let attempts = 0;
     let passed = false;
     
     while (!passed && attempts < MAX_ATTEMPTS) {
       attempts++;
       
       const criticResponse = await anthropic.messages.create({
         model: 'claude-sonnet-4-20250514',
         max_tokens: 2000,
         system: buildCriticSystemPrompt(voiceProfile, isSlideContent),
         messages: [{ role: 'user', content: buildCriticUserPrompt(draft, content, idea) }]
       });
       
       const criticResult = JSON.parse(criticResponse.content[0].text);
       
       if (criticResult.overall_pass) {
         passed = true;
         db.prepare('UPDATE drafts SET status = ?, updated_at = datetime(\'now\') WHERE id = ?')
           .run('critic_approved', draft.id);
       } else if (attempts < MAX_ATTEMPTS) {
         // Auto-revise: call Claude to fix specific issues
         const reviseResponse = await anthropic.messages.create({
           model: 'claude-sonnet-4-20250514',
           max_tokens: 2000,
           system: `You are revising Robin Faraj's content draft. Fix ONLY the issues identified by the critic. Preserve everything that passed. Voice profile:\n${voiceProfile}\n\nReturn the revised content in the same JSON format as the input.`,
           messages: [{ role: 'user', content: `Original draft:\n${JSON.stringify(content, null, 2)}\n\nCritic feedback:\n${JSON.stringify(criticResult, null, 2)}\n\nRevise to address the failures while preserving what passed.` }]
         });
         const revisedContent = JSON.parse(reviseResponse.content[0].text);
         // Update draft content in DB for next critic pass
         db.prepare('UPDATE drafts SET content = ?, updated_at = datetime(\'now\') WHERE id = ?')
           .run(JSON.stringify(revisedContent), draft.id);
         // Update local reference for next loop iteration
         Object.assign(content, revisedContent);
       }
     }
     
     if (!passed) {
       db.prepare('UPDATE drafts SET status = ?, updated_at = datetime(\'now\') WHERE id = ?')
         .run('critic_failed', draft.id);
     }
   }
   ```

4. **buildCriticSystemPrompt function:**
   ```javascript
   function buildCriticSystemPrompt(voiceProfile, isSlideContent) {
     return `You are a content critic reviewing draft posts for Robin Faraj.
   Score each draft on 3 dimensions (0-10 each):
   
   1. VOICE AUTHENTICITY: Does it match the voice profile exactly?
      - Check against the voice profile provided below
      - Red flags: banned patterns, wrong opener style, wrong sentence rhythm
      - Pass threshold: >= 7
   
   2. SLIDE QUALITY${isSlideContent ? '' : ' (skip — not slide content)'}:
      - Hook slide: strong enough to stop scroll?
      - Text: readable, within safe zones, no emoji?
      - Narrative flow: does progression make sense?
      - Pass threshold: >= 7
   
   3. FACTUAL ACCURACY:
      - Every claim must trace to source transcript or idea summary
      - No invented personal experiences
      - Pass threshold: all claims verified (binary — 10 if pass, 0 if fail)
   
   OVERALL PASS: all applicable dimensions pass.
   On failure: return specific rewrite instructions per dimension.
   
   Voice profile:
   ${voiceProfile}
   
   Return valid JSON only: { "voice_score": N, "voice_feedback": "...", "slide_score": N, "slide_feedback": "...", "factual_score": N, "factual_feedback": "...", "overall_pass": true/false, "rewrite_instructions": "..." }`;
   }
   ```

5. **buildCriticUserPrompt function:**
   ```javascript
   function buildCriticUserPrompt(draft, content, idea) {
     return `Review this ${draft.platform} draft:\n\nContent:\n${JSON.stringify(content, null, 2)}\n\nSource material for fact-checking:\nTitle: ${idea.title}\nSummary: ${idea.summary}\nTranscript: ${idea.transcript || 'None available'}\nSource URL: ${idea.source_url || 'None'}`;
   }
   ```

6. **Print summary at end:**
   ```javascript
   const results = db.prepare('SELECT id, platform, status FROM drafts WHERE idea_id = ?').all(ideaId);
   const approved = results.filter(r => r.status === 'critic_approved').length;
   const failed = results.filter(r => r.status === 'critic_failed').length;
   console.log(JSON.stringify({ idea_id: ideaId, total: results.length, approved, failed, results }, null, 2));
   ```

Wrap entire script in async IIFE. Handle JSON.parse errors from Claude with try/catch — if critic response is not valid JSON, treat as a failed attempt and retry.

Per D-15: Brand alignment is NOT a separate check — voice authenticity implicitly covers on-brand tone. The critic rubric has 3 dimensions, not 4.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Generated draft -> critic agent | Draft content from generation pass is untrusted input to the critic |
| Critic JSON response -> DB update | Critic's pass/fail decision drives status updates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Tampering | Critic response JSON parsing | mitigate | Wrap JSON.parse of critic response in try/catch. If invalid JSON, treat as failed attempt and retry. After MAX_ATTEMPTS with parse failures, set status to critic_failed. |
| T-03-13 | Elevation of Privilege | Critic self-review bias | mitigate | Critic is a separate Claude API call with fresh system prompt (D-12). No generation context passed. Only draft text + voice profile + source material provided. |
| T-03-14 | Repudiation | Draft status changes without audit trail | accept | updated_at timestamp tracks last status change. Full audit trail deferred — low risk for single-operator CLI system. |
</threat_model>
