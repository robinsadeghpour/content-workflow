SLIDE 3 — HOW IT WORKS
How It Works 4 / 10

The bridge:
MCP.

MCP (Model Context Protocol) is a standard that lets Claude Code talk directly to external tools. The Obsidian MCP plugin turns your vault into a live database Claude can query.

1
Obsidian runs the MCP server
Install the obsidian-claude-code-mcp plugin. It opens a WebSocket on port 22360 — a live connection to your vault.
2
Claude Code auto-discovers it
No manual config. It can read files, search notes, and write new ones.
3
Bidirectional. Local. Private.
Claude reads context from Obsidian and writes decisions back. Everything stays on your machine — zero cloud dependency.
